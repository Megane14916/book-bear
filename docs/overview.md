# 栞SNS プロジェクト概要

## 1. 目的

本の好きなページや章に感想を「栞」として残し、共有できるモバイルファーストのWeb SNS。

特徴は「栞の流れ」。特定のユーザーが特定の本に投稿した栞を、ページ順ではなく投稿日時の古い順でたどり、読書体験の変化を振り返れる。

## 2. 主な利用の流れ

1. 書名またはISBNで本を探す。見つからない本は手動登録する。
2. 本棚に登録し、ページ番号（任意）と感想を栞として保存する。
3. 初回保存時はログイン操作なしで匿名認証する。匿名ユーザーの栞は非公開のみ。
4. Googleアカウントを連携すると、公開投稿やSNS上の交流ができる。
5. 全体・フォロー中のフィードや、ユーザー×本ごとの「栞の流れ」を閲覧する。

## 3. 機能と優先度

| 優先度 | 機能 |
|---|---|
| P0 | 書名・ISBN検索、書籍の登録、ISBNなしの手動登録 |
| P0 | 匿名認証、Googleアカウント連携、本棚・読書進捗 |
| P0 | 栞の作成・編集・削除、公開／非公開、ネタバレ指定 |
| P0 | 全体フィード、本文表示モード、栞の流れ、プロフィール |
| P1 | フォロー・フォロー中フィード、いいね、返信 |
| P1 | 投稿・ユーザー検索、公開栞のURL共有・Xへの共有 |
| P1 | カメラでのISBNバーコード読み取り |
| P2 | 本の自由リスト、推薦、画像投稿、通知、アプリ内リポスト |

P0：MVPに必須。P1：主要機能として実装を目指す。P2：余裕があれば追加する。

## 4. 主要な仕様

- フィード：投稿日時の新しい順。1回15件ずつ取得し、同じ画面に下へ追加する。
- 栞の流れ：指定ユーザー×指定書籍の栞を投稿日時の古い順で表示する。1回15件ずつ取得する。
- 本文表示：「すべて表示」「タップして表示」を切り替えられる。ネタバレ指定は両モードで初期非表示。
- 公開範囲：栞ごとに公開／非公開を選ぶ。自分の非公開栞はプロフィールから確認できる。
- 本棚：登録した本の一覧は本人のみ。他人のプロフィールには、その人が公開栞をつけた本だけ表示する。
- 匿名ユーザー：本棚・非公開栞は保存できるが、公開投稿・いいね・返信・フォローはできない。
- 書籍：ISBNがあればISBN-13単位で識別する。ISBNなしの本は手動登録し、内部IDで管理する。
- 共有：公開栞のURLコピーとXの投稿画面を開く機能。アプリ内リポストは対象外。

## 5. 技術構成

| 領域 | 技術 |
|---|---|
| フロントエンド | React / TypeScript / Vite / React Router |
| データ取得 | TanStack Query / openapi-fetch / OpenAPI生成型 |
| バックエンド | Hono / Cloudflare Workers / Zod OpenAPI |
| DB | Supabase PostgreSQL / Drizzle ORM / Hyperdrive |
| 認証 | Supabase Auth（匿名認証・Google連携） |
| 書籍情報 | openBD / Google Books API |
| 配信 | Cloudflare Pages（Web）/ Workers（API） |
| 開発・テスト | MSW / Vitest |

フロントエンドはバックエンドのコードを直接importしない。OpenAPI契約とHTTP経由で接続する。
